## 3. Key formula patterns

`General` is the single lookup source; every other sheet is derived. **262 formula cells, 100% of the Main Summary + BOM body.**

| Column | Pattern |
|--------|---------|
| B Material Category | `=IF(ISBLANK(C{r}),"",'General'!$B$7)` |
| C Material Name | `='General'!B9` — a *direct reference*, so renaming a material propagates everywhere |
| D Material ID | `=IF(ISBLANK(C{r}),"",VLOOKUP(C{r},'General'!$B$9:$C$10,2,FALSE))` |
| E Unit Type | `=IF(ISBLANK(C{r}),"",VLOOKUP(C{r},'General'!$B$9:$E$10,3,FALSE))` |
| F Qty **area** | `=ROUND(IF(ISBLANK(C{r}),"",SUMIF('Inventory'!$L1:$L78,$C{r},'Inventory'!$K1:$K78)),2)` |
| F Qty **linear** | `=ROUND(IF(ISBLANK(C{r}),"",'General'!$D$5*(VLOOKUP(C{r},'General'!$J$9:$N$12,3,FALSE))),2)` |
| F Qty **glass** | same but `'General'!$H$5` (2.98 m glazing height) |
| G Quantity Amount | literal `0` — **the only hardcoded body cell**, a user-override slot |
| H Unit Price | `=IF(ISBLANK(C{r}),"",VLOOKUP(C{r},<table>,<priceCol>,FALSE))` |
| I Total cost | `=IF(ISBLANK(C{r}),"",H{r}*G{r})` (area) / `H{r}*F{r}` (linear) |

Five lookup tables on `General`, all row 9+: Floors `$B$9:$E$10`, Ceilings `$F$9:$I$10`, Walls `$J$9:$N$12`, Glass `$O$9:$S$9`, Doors `$T$9:$X$10`. Multipliers on row 5: `D5`=3 (ceiling height), `H5`=2.98 (glass height).

`Main Summary` is the **union** of the five BOM sheets' bodies (rows 5–15) with identical formulas.
Furniture totals: `Furniture Inventory` `J{r}==H{r}*I{r}`; `Furniture Inventory Summary` `G{r}==E{r}*F{r}`.

**Two reference bugs not to replicate:**
1. `Main Summary` B7/B9/B14 test `C5`, and B8/B10/B13/B15 test `C6`, instead of their own row's `C` — a copy-paste slip.
2. `BOM - Glass Partitions` has its header on **row 5** and body on **row 6**; every other BOM sheet is 4/5.

## 8. Findings that contradict the brief's assumptions

### 8.1 The reference's Core legend chip disagrees with its own plan — **decision made**
Legend `Q8` is `#D5BDD6`; the plan PNG draws core as `#A0A0A0` (8,640 px). `#D5BDD6` appears **zero** times in the plan. I unified `palette.json` on `#A0A0A0` so legend and plan agree, and G4 enforces the unified value. This is why G4 "fails" against the reference — that is the gate working. **Flag if you want the opposite choice.**

### 8.2 The reference has NO title card — brief conflicts with reference
The brief requires "logo detectable on the title card frame". qbiq's video has no title card, no end card, no watermark; branding is **in-scene only** (qbiq roundel on wall displays at t≈8.3/12.4/16.5). I took the brief's side — `video-spec.json` `target.branding.mode = "title_card"` with accent `#E8A13C` — and made it a one-word switch: set it to `"in_scene"` and G7 skips the assertion instead of failing. **Orchestrator decides.**

### 8.3 `sqf = m2 × 10.764` is not what the reference does
The reference uses **10.76 exactly** (12.58 → 135.3608; 25.53 → 274.7028 — exact to 4 dp). True conversion is 10.7639. G3 defaults to **10.7639** (correct maths, our own generator) with `--sqf-factor` to override. With 10.7639, **30 of 31** reference rooms fail; with 10.76, all pass. **Pick one and put it in `ground-truth.json`.**
Also: a flat 0.01 tolerance is too tight at scale — the reference's own largest room (173.7 m²) is off by 0.012. G3 uses `max(0.01, sqf × 5e-5)`, still ~7× tighter than the gap a wrong factor creates.

### 8.4 The master plan is **not** full-bleed
`image1.png` is 1040×780 but **71% of the canvas is fully transparent**; the plate occupies only `(3,433)–(1011,755)` = 1008×322. Any area-ratio check must normalise against the **opaque bbox**, not the canvas — G4 does. Assuming full-bleed would make circulation read as 3.7% instead of 12.86%.

### 8.5 `takeoff.ts`'s founding premise is the thing being reversed
The header comment argues the other 8 sheets are *"machinery, not content"*. That machinery **is** the product — it's what makes the workbook a live cost model the client can edit. Agent B is not adding 8 sheets to a working writer; the hand-rolled OOXML writer **cannot express** what's needed. It emits only `inlineStr` and numeric cells. Missing entirely:

1. **Formula cells** — nothing emits `<f>`. Blocks G2.
2. **Image embedding** — no `xl/media`, no `xl/drawings/*`, no drawing rels, no png/jpeg content-type overrides. Blocks G1, G4, G5.
3. **`showGridLines="0"`** — no `<sheetView>` at all. Blocks G1 on all 12 sheets.
4. **Column widths / row heights** — no `<cols>`, no `row ht`. Blocks G5 (180 pt rows).
5. **Merged cells** — blocks the legend header and `General`'s 5 category bands.
6. **Data validations.**
7. **Solid fills** — `styles.xml` has 2 fills and no colours. Blocks G4's legend chips.

Extend the existing `zipStore`/`esc`/`cellXml` scaffolding; don't fork (`.claude/rules/no-bloat.md`). Sheet-name churn to expect: `Furniture Summary` → `Furniture Inventory Summary`; `Wall Schedule` → split into the five `BOM - *` sheets.

### 8.6 Two blockers outside my scope
- **Playwright is not installed** (not in `web/package.json`). G8 and G10 fail with the exact install command. Someone must run `cd web && pnpm add -D playwright && pnpm exec playwright install chromium`.
- **G8 needs UI affordances**: a `data-testid="walk-toggle"` on the walk-mode control (exposing state via `aria-pressed` or `data-active`), and G10 needs a single `data-testid="export-deliverable-pack"` control. Neither exists yet — tell whoever owns the UI.

### 8.7 `.gitignore` — a call for you, I didn't touch it
`docs/reference/qbiq/spec/media/` is already ignored. `docs/reference/qbiq/spec/video-frames/` (10 PNGs, ~3 MB) is **not**, and neither is `scripts/gates/lib/__pycache__/`. The repo's convention is to ignore large reference binaries. The frame-regeneration command is embedded in `video-spec.json` so ignoring them loses nothing.

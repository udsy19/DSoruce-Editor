# Rayon output reference — the drawing-set quality bar

Two Rayon-produced deliverables (PDFs kept on disk, gitignored — large):
- **Cafe Drawing Set Template.pdf** — a full 10-sheet interior set (A.01–A.10): cover, TOC,
  sections/elevations, demolition plan, construction & furnishing plan (door/window schedule),
  lighting/RCP, design + millwork details, furniture & fixtures schedule, material choices/moodboard.
  Every sheet has a title block + key plan + per-sheet scale.
- **10-Seat office pack.pdf** — the same at room scale: seating layout, electrical layout, reflected
  ceiling plan, sections AA/BB, furniture & fixtures cards, moodboard.

This is the target for the **drawing-set generator** — see `docs/design/drawing-set-generator.md`.
Much of the data already exists in our model (zones, walls incl. generated-vs-existing, doors/windows
with dims, component→bank bindings with product cards, the 3D model for sections).
